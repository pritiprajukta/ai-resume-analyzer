# 🧠 AI Resume Screening System

An AI-powered web application that automatically classifies resumes into job roles using Natural Language Processing (NLP) and Machine Learning.

---

## 🚀 Project Overview

This project analyzes uploaded PDF resumes and predicts the most suitable job role using a trained ML model. It also shows:

- Predicted job role
- Confidence score
- Top 3 possible roles

---

## 🎯 Features

✔ Upload resume in PDF format  
✔ Extract text automatically from resume  
✔ AI-based job role prediction  
✔ Confidence score for prediction  
✔ Top 3 suggested job roles  
✔ Simple and clean web interface
